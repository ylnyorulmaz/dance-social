# Dance Social

Working prototype for an invitation-only social network / digital club for dancers.

## v0.1 idea

- dancer profiles
- user-created communities
- posts, questions and polls
- one-off and recurring events
- invitation graph
- clearly labeled utility and moderation bots
- future dancer tools such as metronome, BPM and event discovery

## Launch strategy

The product is open to social dance communities broadly, while the initial distribution can start with a dense seed community such as Istanbul Lindy Hop.

## Current state

Static landing-page prototype. The generated dance-circle logo is embedded directly in `index.html` for the first prototype commit.

## Next

Move the beta to an app stack, likely Lovable + Supabase, and test the smallest loop:

`invite → profile → community → post/event → interaction → return`
